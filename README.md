# Simple Interface for Real-Time User Interaction

## 📌 Project Overview

**Simple Interface for Real-Time User Interaction** is a lightweight web-based application developed using Python and Streamlit.

The project provides a clean and responsive interface where users can enter messages and receive immediate system responses. It demonstrates basic real-time interaction, message handling, timestamps, and a user-friendly interface.

---

## 🎯 Objectives

- Create a simple real-time interaction interface
- Provide an easy-to-use chat-style UI
- Display user and system messages
- Show message timestamps
- Provide immediate responses to user input
- Demonstrate frontend and backend integration using Streamlit

---

## ✨ Features

- 💬 Real-time user interaction
- 👤 Username input
- 📨 Message sending
- 🤖 Automatic system responses
- 🕒 Message timestamps
- 🗑️ Clear message option
- ⌨️ Easy keyboard-based interaction
- 📱 Responsive interface
- 🎨 Modern dark-themed UI
- HTML, CSS and JavaScript integrated into the Python application
